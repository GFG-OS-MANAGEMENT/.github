# GFG BVCOE

**GeeksforGeeks Student Chapter · BVCOE, New Delhi**

A student-led technology community fostering coding, collaboration, and practical learning.

### Our Community
- Have 100+ Active Members.
- Host coding events, workshops, and collaborative projects.
- Encourage open-source participation and peer-to-peer learning.
- Build a collaborative space for beginners to develop and share their technical work.

### GFG-BVCOE Open Source
- Contribute to 24+ Active Open Source projects in 8 different Tracks
- You will improve Development Skills and Gain Experience by working on some good and very useful projects
- Contributors will get participation certificates and Winners will get winning certificate.
